# FlashCard Pro - 觀光餐旅專業單字記憶系統

專為觀光餐旅科系學生量身打造的雙語數位單字記憶與自主學習系統。

## 🌟 核心功能特色
- 🎓 **免密碼座號選擇**：首頁直觀挑選 1 ~ 35 號座號，永久儲存狀態，免去記密碼煩惱。
- 🔊 **跨平台 100% 語音發音**：支援 Web Speech API 系統語音與美式在線 MP3 自動切換，完美支援 iOS Safari、Android Chrome 與 Windows。
- 🗺️ **關卡地圖與間隔重複記憶**：翻卡記憶、聽力測驗、雙語連連看配對大挑戰。
- 🎉 **優化通關視覺效果**：慶祝彩帶 1.2 秒自動消退清理，畫面流暢不遮擋。
- 👩‍🏫 **教師管理端**：防側目密碼保護與成績圖表管理。
